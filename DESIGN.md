# Design System — Sync / PrimeOS

## Colors
- **Primary Navy**: #1B2A4A (sidebar, headers, anchoring)
- **Accent Blue**: #2F6BFF (CTAs, links, active states)
- **Accent Hover**: #1D4FD7
- **Scaffold**: #EEF1F6 (background)
- **Surface**: #FFFFFF (cards, panels)
- **Border**: #E2E8F0
- **Text Primary**: #1E293B
- **Text Secondary**: #64748B
- **Text Muted**: #94A3B8
- **Success**: #10B981
- **Warning**: #F59E0B
- **Error**: #EF4444

## Typography
- **Primary Font**: Inter (variable weight)
- **Mono Font**: JetBrains Mono
- **Scale ratio**: 1.125 (Major Second)
- **Body**: 14px / 400
- **Heading 1**: 24px / 700
- **Heading 2**: 20px / 600
- **Heading 3**: 16px / 600
- **Caption**: 12px / 500

## Spacing
- Base unit: 4dp
- Input height: 48dp
- Card padding: 20-24dp
- Section gap: 24-32dp

## Corners
- Cards: 12dp
- Buttons/Inputs: 10dp
- Badges: pill (full radius)
- Avatars: full circle

## Elevation
- No box-shadows on cards
- Borders only: 1px solid #E2E8F0
- Active/focus: 2px ring accent blue

## Components
- **Sidebar**: Dark navy (#1B2A4A) background, white text, 260px width
- **Cards**: White surface, 1px border, 12dp radius, 20dp padding
- **Buttons**: 48dp height, 10dp radius, Inter 500
- **Icons**: Lucide Icons, 20px default
